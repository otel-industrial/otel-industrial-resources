# Modbus Receiver

**Status:** External project.

A Modbus TCP receiver for the OpenTelemetry Collector, extending industrial observability to one of the most widely deployed protocols in manufacturing and automation. Supports coils, discrete inputs, holding and input registers, multiple data types and byte orders, and includes a built-in simulator for local testing without real hardware.

Repository: [lukaszciukaj/modbusreceiver](https://github.com/lukaszciukaj/modbusreceiver)
